# Asset Compass 起動手順

WindowsでAsset Compassを起動し、PCまたは同じLAN内のスマートフォンから利用する手順です。

## 1. PowerShellを開く

WindowsでPowerShellを起動します。

## 2. Asset Compassのフォルダへ移動する

```powershell
cd "$HOME\Documents\Codex\asset-compass"
```

実際の保存先が異なる場合は、パスを置き換えてください。

## 3. サーバーを起動する

```powershell
node .\server.js
```

サーバーは既定でポート `8766` を使います。環境変数 `ASSET_COMPASS_PORT` が設定されている場合は、その値が使われます。

## 4. 起動を確認する

コンソールに次のような行が表示されたら、PC内アクセス用サーバーが起動しています。

```text
PC内アクセス: http://127.0.0.1:8766
```

同じLANから接続できるプライベートIPv4アドレスが見つかった場合は、次のような行も表示されます。

```text
同一LANアクセス: http://192.168.1.100:8766
```

表示されるアドレスはPCのネットワーク環境によって異なります。LAN用アドレスが見つからない場合は、その旨がコンソールに表示されます。

## 5. PCからAsset Compassを開く

ブラウザーで次のURLにアクセスします。

```text
http://127.0.0.1:8766
```

## 6. スマートフォンから開く

1. PCとスマートフォンを同じWi-FiなどのLANに接続します。
2. 起動時に表示された「同一LANアクセス」のURLを確認します。
3. URLのIPアドレスを使い、スマートフォンのブラウザーで次の形式にアクセスします。

```text
http://<PCのプライベートIPv4アドレス>:8766
```

例：

```text
http://192.168.1.100:8766
```

IPアドレスはPCごとに異なります。`127.0.0.1` はアクセスした端末自身を指すため、スマートフォンからPCへ接続する場合は使わないでください。

LAN待受は既定で有効です。`ASSET_COMPASS_BIND_LAN=false` が設定されている場合はPC内アクセスのみになります。また、Windowsファイアウォール等が通信を遮断している場合、スマートフォンから接続できないことがあります。

## 7. サーバーを終了する

起動に使ったPowerShellを選択し、`Ctrl + C` を押します。サーバーを利用している間は、そのPowerShellを閉じないでください。

## 起動できない場合

### `node` コマンドが認識されない

Node.jsが利用できるか確認します。

```powershell
node -v
```

バージョンが表示されない場合は、Node.jsのインストールまたはPATHの設定を確認してください。Asset CompassはNode.jsの組み込みSQLite機能（`node:sqlite`）を使うため、その機能が利用できるNode.js環境が必要です。

### Asset Compassのフォルダが見つからない

現在の場所を確認します。

```powershell
Get-Location
```

保存先に合わせて、手順2の `cd` のパスを変更してください。

### スマートフォンから接続できない

- PCとスマートフォンが同じLANに接続されているか確認します。
- `127.0.0.1` ではなく、起動ログに表示された「同一LANアクセス」のIPアドレスを使います。
- サーバーが起動したままか確認します。
- `ASSET_COMPASS_BIND_LAN=false` が設定されていないか確認します。
- Windowsファイアウォール等でNode.jsの通信が遮断されていないか確認します。
