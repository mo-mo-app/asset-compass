# Asset Compass ロードマップ

このロードマップでは、実施が決まっている内容と、採用・時期・バージョンが未確定の候補を分けて記載します。未確定の機能にバージョン番号は割り当てません。

## 完了したリリース

### v0.2.7 — 資産目標シミュレーション

- 資産目標シミュレーションの入力・結果表示を追加
- 資産推移グラフと年ごとのリターン一覧を追加
- 保有資産の数値精度、iDeCo取得金額、分類・銘柄変更時の入力保護を実装
- API保存境界の検証と既存データ互換処理を実装

資産目標条件の保存とTOP画面への達成率表示は、このバージョンでは実装していません。セクター等の分類情報、TOPの資産配分拡張、配当管理、Quest Modeも引き続き下記の決定済み・将来候補に分けて管理します。

## バージョン運用

- 原則として `v0.X.9` は、リファクタリング、レイアウト調整、技術的負債の整理、小さな不具合修正に使います。
- 新機能追加と整備回を分けます。
- 各機能ブロックを安定させながら `v1.0.0` を目指します。
- 候補機能へは、着手を決めるまでバージョン番号を付けません。
